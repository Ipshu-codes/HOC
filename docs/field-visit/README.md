# Field-visit sheets

Printable question sheets for the visits before launch: Nepali first, then English, with lines for the answers. Each sheet is a Markdown file (to edit) and an A4 PDF (to print).

| Sheet | For | Blocks launch |
|---|---|---|
| [ward-office.md](ward-office.md) / `.pdf` | Ward office | emblem, Nani approval, chairperson name, ward email, contact details as shown |
| [nanak-math-mahant.md](nanak-math-mahant.md) / `.pdf` | Mahant of Nanak Math | permission for the inner-shrine photos |
| [mhepi-priest.md](mhepi-priest.md) / `.pdf` | Chief priest of Mhepi Ajima | nothing (all after launch) |
| [site-visit.md](site-visit.md) / `.pdf` | Team on site | nothing (all after launch) |
| [luniva-nepali-review.md](luniva-nepali-review.md) / `.pdf` | Luniva (Nepali review) | the whole sheet |

Each question is marked **[BLOCKS LAUNCH]** (the site can't go live without the answer) or **[after launch]** (can be added later). When answers come back, put them into `content/` and tick them off in `MISSING_INFO.md`.

The screenshots in `img/` are of the Nepali pages as they were on 17 Nov 2026 (main). The PDFs were made from these Markdown files in Microsoft Edge (A4, Nirmala UI font). After editing a sheet, open the `.md` in a Markdown viewer and print it to PDF, or ask Claude to regenerate it.

The Nepali wording of the sheets is by Claude.
